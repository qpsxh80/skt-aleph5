## 1. 개선할 기능 명칭 및 목표
- **기능 명칭:** 지진·태풍 복합 재난 시각화 및 2단계 LLM 연계 재난 브리핑 시스템
- **기반 소스:** `skt-aleph4` (USGS 글로벌 지진 실시간 관제 3D 대시보드)
- **개선 목표:**
  1. 기존 지진(원형 마커 + 규모별 반경) 중심 관제에 **태풍 데이터(사이클론 중심 마커 + 이동 경로 Polyline + 강풍 영향권 Circle)**를 3D 구체 지도 위에 복합 시각화
  2. **여러 LLM 연계 파이프라인 구현:**
     - **1단계 LLM (위험도 분석가):** 지진 관측 수치와 태풍 관측 수치를 종합하여 복합 재난 위험 등급(주의/경보/심각) 판정 및 피해 요인 분석 JSON 반환
     - **2단계 LLM (행동요령 수립가):** 1단계의 분석 결과를 인계받아 지역별 시민 행동요령, 대비 수칙, 비상 대피 브리핑 마크다운 리포트 생성
